### rvs 26.9.23 语法事实（实测）
- 不支持 `export`、`$VAR = 值` 赋值、`$(...)` 命令替换 → Parse error
- `if` 必须带括号：`if (<命令>) { } else { }`，按命令退出码判真假
- 内置别名优先于外部程序：`mv`=move-item 不认 `-f`，需 `/bin/mv`；`git`/`bash`/`adb` 直接透传
- `rvs --dry-run <script>` 可验语法，不会真跑副作用
